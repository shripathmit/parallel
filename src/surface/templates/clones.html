How clones are built

1. Mine — Parallel FindAll scans FDA records (warning letters, 510(k) decision summaries, recalls) and the Task API distills recurring behavior patterns per stakeholder. 2. Encode — patterns become the system prompts above, refreshed as new records arrive. 3. Simulate — every analyzed change is run through all three clones in parallel via the Chat API, producing the side-by-side predictions you see on each event.
