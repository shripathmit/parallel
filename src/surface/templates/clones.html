How clones are built

1. Mine — Parallel FindAll scans FDA records (warning letters, 510(k) decision summaries, recalls) and the Task API distills recurring behavior patterns per stakeholder into the library below. 2. Match — for each new change, a deterministic matcher scores every pattern by trigger coverage × confidence and hands the top matches to that stakeholder's clone. 3. Reason — the clone predicts from the analysis plus its matched patterns, and cites which patterns fired.

Pattern library

The evidence base. Each pattern names its trigger phrases, typical actions, supporting FDA records, and confidence. Mined patterns arrive via the mining pipeline; demo patterns are distilled from the real publications in the demo set.
